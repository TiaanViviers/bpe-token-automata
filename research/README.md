# Research materials

Locally managed research-paper sources and converted Markdown for collaboration.

```text
research/
├── sources/     # original PDFs and downloads (*.pdf gitignored)
├── markdown/    # Marker (or other) conversions for shared reading
├── notes/       # human-reviewed interpretation and verification notes
└── README.md
```

This directory is **not** part of the university GitLab export (`project/` subtree only).

## Project specification

| Role | Path |
|---|---|

- `notes/` — working notes
