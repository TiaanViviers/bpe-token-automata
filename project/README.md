# BPE Token Automata

Finite-state constructions for canonical BPE tokenization (Stellenbosch University CS345).

**Status:** scaffolding — project structure and tooling only; no automata or tokenizer algorithms yet.

## Installation

Requires Python 3.12+ and [uv](https://docs.astral.sh/uv/).

```bash
cd project
make install
```

## Quality checks

```bash
make check
```

This runs formatting checks, linting, type checking, and tests.
